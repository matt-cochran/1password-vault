# Design documents

For contributors. Users want the [README](../../README.md) and the guides in [docs/](..).

- [requirements.md](requirements.md): concept of operations, functional (FR-n) and security (SR-n) requirements, and acceptance criteria. Normative: code and commits cite these IDs, and a change to a decision updates this file.
- [multi-cloud-targets.md](multi-cloud-targets.md): the design for Azure, AWS and GCP targets (FR-28 to FR-33) and its delivery phases.
- [plans/](plans/): implementation plans, one per phase.
- [spike-d0-findings.md](spike-d0-findings.md): the original investigation of `op` and `flyctl` behaviour that the Fly adapter relies on.
